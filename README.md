# 🚀 Bruno Borjes — Full Stack Portfolio & Interactive Hub

> Landing page profissional, moderna e de alta conversão desenvolvida para apresentar habilidades de desenvolvimento Full Stack, portfólio de projetos, serviços especializados e uma experiência interativa diferenciada.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído sem dependências pesadas ou frameworks complexos, focando em **performance extrema**, **código limpo** e **boas práticas de engenharia de software**:

* **HTML5** (Marcação semântica e acessibilidade estrutural)
* **CSS3** (Variáveis CSS, Flexbox, CSS Grid, media queries responsivas e animações suaves)
* **JavaScript (ES6+)** (Manipulação DOM, interatividade do header, formulários e lógica do minigame)
* **Google Fonts** (Tipografia moderna com *Plus Jakarta Sans* e *JetBrains Mono*)
* **FontAwesome 6** (Ícones vetoriais otimizados)

---

## ✨ Principais Funcionalidades

* **Hero Impactante com Terminal Interativo:** Apresentação visual limpa com elementos que remetem ao ambiente de desenvolvimento profissional.
* **Seção de Sobre Mim & Trajetória:** Mensagem direta e transparente transmitindo autoridade e foco em arquitetura de software limpa.
* **Arsenal Tecnológico:** Exibição elegante das principais ferramentas do stack (HTML5, CSS3, JavaScript, React, Node.js e Git).
* **Portfólio de Projetos:** Cards modernos com prévias, tags de tecnologias e botões de acesso rápido a demonstrações e código-fonte.
* **Serviços Especializados:** Listagem comercial clara de soluções (Landing Pages, Sites, Sistemas Web, Aplicações SPA, Automações e Manutenção).
* **Minigame Exclusivo (*"Desafio do Desenvolvedor"*):** Um jogo em HTML5 Canvas puro construído em JavaScript, onde o visitante interage coletando símbolos de código e desviando de bugs, com contagem de score e recorde salvos em `localStorage`.
* **Seção de Contato & Conversão:** Formulário interativo com feedback visual, canais diretos e integração fluida com **WhatsApp** (botão flutuante + contato direto).
* **Barra de Progresso de Rolagem:** Indicador dinâmico no topo da página que acompanha o scroll do usuário.
* **Design Totalmente Responsivo:** Layout rigorosamente adaptado para computadores, tablets e smartphones com menu mobile otimizado.
